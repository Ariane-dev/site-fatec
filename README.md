# Site FATEC

Projeto desenvolvido para uma atividade de desenvolvimento web.

## Sobre o projeto

Este projeto apresenta uma página web desenvolvida utilizando HTML e CSS, com informações sobre a grade de disciplinas do curso.

## Tecnologias utilizadas

- HTML5
- CSS3

## Acesse o site

[Visualizar o site](https://ariane-dev.github.io/site-fatec/)

## Estrutura do projeto

- `index.html` — página principal
- `grade.html` — página com a grade de disciplinas
- `estilo.css` — estilos da página principal
- `estilograde.css` — estilos da grade
- `img/` — imagens utilizadas no projeto
